# 用量小字条（待实际应用验证）

在每轮「用时」右边加一条小字：

用时 13 秒 ›　 本轮 25.5万 Token · 估算 2.02 Credits

它使用本机用量实验室的数据，按页面真实的对话 ID 和轮次 ID 精确对应。鼠标悬停显示输入、缓存、输出和调用次数。没有独立侧栏，每 10 秒更新，不调用模型。

## 使用

1. 保存正在做的工作，然后用 Command+Q 正常退出 Codex。
2. 双击「启动用量小字条.command」，阅读本机调试端口说明并选择是否继续。
3. Codex 打开后，保留启动的小终端窗口。

仅在主页面地址为 app://-、能识别真实轮次并有本地记录时显示。若应用更新使结构变化，会保持不显示；不会拿最近的对话数据顶替。

## 撤销

在启动终端按 Control+C，脚本会移除已加的小字并退出。或结束启动程序后双击「移除用量小字条.command」。正常退出 Codex 并从原图标启动，也会清除所有临时改动和调试端口。

此实现不修改应用包、app.asar、签名、CSP、安全设置和插件文件，也不装开机任务。临时的 127.0.0.1:9335 调试连接能控制应用页面，本机其他进程也可能连接；关闭应用后端口结束。
